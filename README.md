🛡️ VectorSpy

Automated Cybersecurity Assessment and Risk Visualization Platform

VectorSpy is a Python and Flask-based cybersecurity assessment platform designed to provide a centralized interface for performing basic and authorized security assessments.

The platform combines network scanning, web security assessment, technology detection, rule-based risk detection, findings management, and scan history into a single web-based dashboard.

📖 Project Overview

VectorSpy is an automated cybersecurity assessment platform developed using Python and Flask.

The primary purpose of VectorSpy is to provide a centralized interface through which users can perform authorized security assessments and view collected security information in an organized manner.

The current V1 implementation provides three major assessment modules:

Network Security Assessment

Basic Web Security Assessment

Technology Finder

The results generated by these modules are processed using a rule-based risk detection system and stored in an SQLite database.

Users can view findings, risk information, recommendations, dashboard statistics, and scan history through the web interface.

🎯 Objectives

The main objectives of VectorSpy are:

Provide a centralized cybersecurity assessment dashboard.

Perform network reconnaissance using Nmap.

Identify open ports, services, and service versions.

Perform basic web security configuration checks.

Identify technologies used by web applications.

Assign risk levels to identified findings.

Store assessment results using SQLite.

Provide security recommendations.

Maintain scan history.

Provide an easy-to-use web interface for security assessment.

⚙️ Installation and Setup

🪟 Windows

1. Verify Python

python --version

2. Verify Git

git --version

3. Verify Nmap

nmap --version

If Nmap is not installed, install Nmap and Npcap before continuing.

4. Clone the Repository

git clone https://github.com/USERNAME/VectorSpy.git
cd VectorSpy

Replace USERNAME with the actual GitHub username.

5. Open the Project

code .

6. Create Virtual Environment

python -m venv venv

7. Activate Virtual Environment

.\venv\Scripts\Activate.ps1

If PowerShell blocks script execution:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Then:

.\venv\Scripts\Activate.ps1

8. Upgrade pip

python -m pip install --upgrade pip

9. Install Dependencies

pip install -r requirements.txt

10. Run VectorSpy

python app.py

Open:

http://127.0.0.1:5000

🐧 Kali Linux

1. Update System

sudo apt update
sudo apt upgrade -y

2. Install Required Packages

sudo apt install python3 python3-pip python3-venv git nmap -y

3. Verify Installations

python3 --version
pip3 --version
git --version
nmap --version

4. Clone VectorSpy

git clone https://github.com/USERNAME/VectorSpy.git
cd VectorSpy

5. Open Project in VS Code

code .

If the code command is unavailable, open the VectorSpy folder manually in VS Code.

6. Create Virtual Environment

python3 -m venv venv

7. Activate Virtual Environment

source venv/bin/activate

After activation, the terminal should show:

(venv)

8. Upgrade pip

python -m pip install --upgrade pip

9. Install Dependencies

10. Verify Nmap

11. Run VectorSpy
